# Правила проекта для AI-агента

Этот файл агент читает при каждом запуске в этой папке. Здесь описано, что за проект и чего в нём делать нельзя.

Дописывайте его по ходу курса: чем точнее описан проект, тем меньше агент выдумывает.

## Что это за проект

Учебный проект ML-трека, модуль 1 - инфраструктура и среда. Домашнее задание: ноутбуки в `notebooks/`, переиспользуемый код в `src/`, данные локально в `data/` (в git не попадают).

Данные для домашки лежат в публичном ClickHouse: таблица `nyc_taxi.trips_small` - 3 млн поездок такси Нью-Йорка за июль-сентябрь 2015 года. Ничего создавать и заливать не нужно, доступ только на чтение.

## Стек

- Python 3.11, виртуальное окружение в `.venv`
- pandas, numpy, matplotlib, seaborn
- ClickHouse через `clickhouse-connect`, подключение только через `src/db.py`
- Jupyter Lab, ядро называется `ml-course`

## Правила

- 🔴 Никогда не писать доступы (хост, логин, пароль) в код или в ноутбук. Всё берётся из `.env` через `src/db.py`.
- 🔴 Никогда не коммитить `.env`, содержимое `data/` и выводы ячеек ноутбука.
- 🔴 Не менять `notebooks/hw01_task.ipynb` - это файл с заданием от преподавателя.
- Агрегировать данные на стороне ClickHouse, а не тянуть миллионы строк в pandas. База публичная и общая.
- Если код нужен второй раз - выносить его из ноутбука в `src/`, а не копировать.
- Новые библиотеки добавлять в `requirements.txt` с зафиксированной версией, а не ставить молча через pip.
- Объяснять, что делает предложенный код. Это учебный проект, готовый ответ без объяснения бесполезен.
